# LavaRapido

LavaRapido é um sistema web desenvolvido em PHP, MySQL, HTML e CSS para auxiliar no gerenciamento de veículos e serviços de um lava-rápido.

O sistema possui autenticação de usuários e permite realizar operações de cadastro, consulta, edição e exclusão de registros. Os veículos podem ser organizados por categorias, facilitando o gerenciamento dos serviços realizados.

## Tecnologias

- PHP
- MySQL
- HTML
- CSS
- Bootstrap

## Funcionalidades

- Autenticação de usuários
- Cadastro de veículos
- Visualização de veículos cadastrados
- Edição de registros
- Exclusão de registros
- Organização de veículos por categorias
