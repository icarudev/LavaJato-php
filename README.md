# LavaRapido

Sistema web para gerenciamento de veículos e serviços de um lava-rápido.

## Tecnologias

- PHP
- MySQL
- HTML
- CSS
- Bootstrap

## Funcionalidades

- Login de usuários
- Cadastro de veículos
- Visualização de veículos cadastrados
- Edição de registros
- Exclusão de registros
- Organização por categorias
- Validação de dados
